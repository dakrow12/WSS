# Wilderness Survival System (WSS)

## Overview
The Wilderness Survival System is a Java-based simulation game where players survive in a procedurally generated wilderness. Players interact with the environment, collect items, and trade with AI-controlled traders.

## Features
- Random terrain and item generation
- Difficulty selection and map size options
- Player inventory management
- AI traders and item trading
- Console-based interface (GUI optional)

## Setup Instructions
1. Clone the repository:
2. Open the project in your Java IDE (e.g., IntelliJ IDEA or Eclipse).
3. Compile and run `Main.java`.

## How to Play
- Choose map size and difficulty.
- Explore the terrain and collect items.
- Locate traders and exchange items.
- Survive as long as possible.
